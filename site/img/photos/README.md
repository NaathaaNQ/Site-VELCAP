Dépose ici les vraies photos (mêmes noms de fichier que ci-dessous) — elles
s'afficheront automatiquement à la place des placeholders, au prochain
`npm run build:site`.

- photo-manifesto.jpg → section "une seule licence" (coureurs / équipe) — N&B
- photo-band.jpg      → bandeau émotion après le carrousel (arrivée, accolade) — COULEUR
- photo-engage.jpg    → section s'engager (équipe sous l'arche) — N&B
